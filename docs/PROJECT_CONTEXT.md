# Project Context

This is an independently designed portfolio project for demonstrating data-analyst capabilities in a retail/customer-engagement context.

Flow: raw retail data → Python/Pandas ETL → SQLite → SQL analytics → RFM → Streamlit → SQL performance view → hosted URL.

Core narrative: a retail team wants to improve retention; the analyst identifies customer value and inactivity patterns and translates them into loyalty, cross-sell, onboarding, win-back and reactivation priorities.

Limitations: SQLite demo database, environment-dependent timings, heuristic segmentation, non-production dataset.

It is not an internal Xeno system and does not use proprietary Xeno data.
