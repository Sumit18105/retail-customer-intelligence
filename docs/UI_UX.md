# UI/UX Specification

Navigation: Overview | Customer Intelligence | SQL Performance.

Sidebar: date range, segment, category, city/region.

Overview: KPI cards → revenue trend → category revenue → top customers → business insight.

Customer Intelligence: segment distribution → revenue by segment → customer RFM table → recommended action.

SQL Performance: query description → before/after timings → EXPLAIN plans → explanation.

Design principles: restrained professional dashboard, consistent spacing, readable tables, question-oriented chart titles, useful empty/error states.
